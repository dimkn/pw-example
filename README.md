# pw-example

Just a small example repository that demonstrates how a web testing framework might look like.

## What's used here

- Playwright for everything related to testing itself,
- GitHub actions for CI,
- BDD (for the sake of demonstration, TBD),
- Reporting (TBD),
- Linters (to keep code quality high),
- Visual testing.

## What tests we have

There is one main use case that is being tested in this demonstration:
1 Open a search engine,
2 Lookup a weather website,
3 Check that the weather data is there.
